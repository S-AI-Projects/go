# Word Count Maintenance & Test Generation Guide

This document records the route, generator architecture, file classifications, and canonical case origins for `exercises/practice/word-count`.

## Test Generation Route

The test suite in `cases_test.go` is generated from Exercism's canonical problem-specifications data filtered through `.meta/tests.toml`:

```
exercism/problem-specifications (canonical-data.json)
                         │
                         ▼
        .meta/tests.toml (case inclusions/exclusions)
                         │
                         ▼
        .meta/gen.go + track gen package (gen/gen.go)
                         │
                         ▼
        exercises/practice/word-count/cases_test.go
```

1. **Canonical Test Data**: Defined in `exercises/word-count/canonical-data.json` in the `exercism/problem-specifications` repository under property `countWords`.
2. **Track Filter Configuration**: `.meta/tests.toml` tracks all canonical case UUIDs. Any entry marked `include = false` (such as obsolete or superseded tests) is excluded during generation.
3. **Template & Generator**: The Go track does **not** use per-exercise Jinja (`.j2`) templates. Instead, the generator uses Go's standard library `text/template` in `.meta/gen.go` together with the shared generator package (`gen/gen.go`, `gen/filter.go`, `gen/toml.go`, `gen/local.go`, `gen/remote.go`).
4. **Generated Test Definitions**: `.meta/gen.go` unmarshals the filtered JSON into `testCase` structures, populates the template, formats the source with `gofmt`, and writes `cases_test.go`.

## File Classification: Generated vs Hand-Maintained

| File | Status | Description |
|------|--------|-------------|
| `cases_test.go` | **Generated** | Auto-generated by `.meta/gen.go`. Do not edit manually. |
| `go.mod` | **Generated** | Managed and updated automatically by `.meta/gen.go` using version config in `gotools/config.json`. |
| `.docs/instructions.md` | **Generated / Synced** | Synchronized from canonical problem-specifications via `configlet sync`. |
| `word_count.go` | **Maintained by Hand** | Learner stub file containing the `Frequency` type definition and unsolved panic stub. |
| `word_count_test.go` | **Maintained by Hand** | Exercise test runner running `TestWordCount` across test cases from `cases_test.go`. |
| `.meta/example.go` | **Maintained by Hand** | Reference solution used to verify test validity. |
| `.meta/gen.go` | **Maintained by Hand** | Generator script defining the Go template (`tmpl`) and target data structure. |
| `.meta/config.json` | **Maintained by Hand** | Exercise configuration (authors, contributors, solution/test/example file paths). |
| `.meta/tests.toml` | **Maintained by Hand** | Track inclusion/exclusion decisions and maintainer rationales (`comment` keys). |
| `.docs/introduction.md` | **Maintained by Hand** | Introductory exercise background text. |

## Canonical Case Sources & Anchored Test Cases

The test suite covers 14 active canonical test cases (with 1 superseded case excluded):

1. **`include numbers`** (`d2e5cee6-d2ec-497b-bdc9-3ebe092ce55e`)
   - **Input**: `"testing, 1, 2 testing"`
   - **Expected**: `Frequency{"1": 1, "2": 1, "testing": 2}`
   - **Source**: Canonical problem-specifications. Anchors numeric token handling (`: 1, ` counts) where digits are treated as words.
   - **Rationale**: Verifies that standalone numbers are recognized as distinct words.

2. **`multiple spaces not detected as a word`** (`c5f4ef26-f3f7-4725-b314-855c04fb4c13`)
   - **Input**: `" multiple   whitespaces"`
   - **Expected**: `Frequency{"multiple": 1, "whitespaces": 1}`
   - **Source**: Problem-specifications PR #1446 (commit `d793398`).
   - **Rationale**: Prevents empty substrings created by repeated whitespace from being counted.

3. **`alternating word separators not detected as a word`** (`50176e8a-fe8e-4f4c-b6b6-aa9cf8f20360`)
   - **Input**: `",\n,one,\n ,two \n 'three'"`
   - **Expected**: `Frequency{"one": 1, "three": 1, "two": 1}`
   - **Source**: Problem-specifications PR #1446 (commit `d793398`).
   - **Rationale**: Prevents alternating punctuation and whitespace characters from creating empty token entries.

4. **`quotation for word with apostrophe`** (`6d00f1db-901c-4bec-9829-d20eb3044557`)
   - **Input**: `"can, can't, 'can't'"`
   - **Expected**: `Frequency{"can": 1, "can't": 2}`
   - **Source**: Problem-specifications PR #2042 (commit `ef25a61`), synced to Go track in PR #2924 (commit `b0fac275`).
   - **Rationale**: Ensures single quotes acting as outer quotation marks are trimmed while inner apostrophes in contractions are preserved.

5. **`with apostrophes`** (`4ff6c7d7-fcfc-43ef-b8e7-34ff1837a2d3`)
   - **Input**: `"'First: don't laugh. Then: don't cry. You're getting it.'"`
   - **Expected**: `Frequency{"cry": 1, "don't": 2, "first": 1, "getting": 1, "it": 1, "laugh": 1, "then": 1, "you're": 1}`
   - **Source**: Problem-specifications PR #1982 (commit `5753fef`).
   - **Rationale**: Reimplements older case `4185a902-bdb0-4074-864c-f416e42a0f19` (`include = false`) with comprehensive punctuation and multiple contractions.

## Reproduction Commands

To reproduce the generated `cases_test.go` from source data:

1. **Generate Single Exercise**:
   ```bash
   GO111MODULE=off go run exercises/practice/word-count/.meta/gen.go
   ```

2. **Track-Wide Generation / CI Entry Point**:
   ```bash
   ./bin/run-generators [GITHUB_TOKEN]
   ```
   (Invoked by CI workflow `.github/workflows/run-configlet-sync.yml`)

3. **Synchronize Canonical Metadata**:
   ```bash
   configlet sync --update -e word-count
   ```

4. **Run Verification Tests Against Reference Solution**:
   ```bash
   # In a temporary scratch module with .meta/example.go copied to word_count.go:
   go test -count=1 ./...
   ```
